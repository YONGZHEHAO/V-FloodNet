## 识别和验证的区分

- 全部 `numeric_depth_m` 为null，没有人为补0米、人物身高、车轮尺寸、标志杆高度、训练掩膜或实测真值。水体掩膜本身不是水深。
- 时间和地点可能仅为原作者陈述、发表日期或背景参照。`related_event_ids`不能证明拍摄在事件核心时间窗内，不能直接当作该站点/事件的验证点。
- 屋前地坪、农业棚间通道、山地沟道和城市公共街面分别标记。异地水情可作为识别样本；不能移作郑州事件证据。
- 一个视频的多帧共享来源，不能按帧数当独立观测。播放器截图保留UI和文字，先核 `preprocessing_required` 与场景区域；原图未裁切、拉伸或生成式修图。
- 当前CPU配置主要支持水体分割和具备合适停止标志时的参考物路线。无合适标志不能套默认尺寸；人物路线需要另配GPU及SMPL许可，且真实身高需独立核实；车辆不是当前CLI的单独估深模式。
- 在本次核读的8deaafb版本中，后处理存在静态待修项：全零输入可能被返回全水（`myutils/data.py:17–37`）；本次未修改/验证该算法，也不以推理结果声称识别准确率。后续运行须核对原图、掩膜和参照物。
