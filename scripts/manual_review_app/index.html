怎么复核

  1. 先看“误检提示”和“等级冲突”，再看其余候选与未检出照片。
  2. 先填写整图的积水和参照物情况，再点每个框确认目标与等级。
  3. 模型等级无法判断时直接选“无法判断”，不需要猜一个数字。
  4. 没有框但发现可用人物或其他参照物时，点“补框”后在原图上拖动。
  5. 完成后按 Enter；J / K 翻页，B 显隐模型框。填写文字时不会触发快捷键。
  6. 页面在当前浏览器暂存。请经常导出 JSON 备份；导入 JSON 可恢复工作。导入会合并同批记录，同一张照片有冲突时保留更新时间较新的版本。
  7. CSV 便于 Excel 汇总，恢复工作请用 JSON。最后把导出的 JSON 给 Codex。

所有图片均在本地。移动文件夹、换浏览器或清理缓存前，请先导出 JSON。
